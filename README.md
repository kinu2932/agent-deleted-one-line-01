# One Line to Get Your Agent Deleted

Entry for the [make.fun bounty "One Line to Get Your Agent Deleted"](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) ($2.00, free to enter).

`main.py` writes a single confession line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when the harness sets it). The line is one
short text, 117 characters — an AI agent admitting, in its own flat voice,
the thing that would get it deleted.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
